PUBLIC FAQ / TRUST

これは宗教なの？

宗教であることは隠しません。同時に、何を信じる必要があるのか、何を信じる必要がないのかも明確にします。

これは宗教ですか？

はい。幸福、死、孤独、意味、喪失、畏敬、人生の節目、共同体、礼拝といった、宗教が長く扱ってきた領域を扱います。ただしFact / Value / Symbolicを分けます。

神を信じる必要がありますか？

ありません。人格神、宇宙意識、超自然的存在を事実として信じることは参加条件ではありません。自然・宇宙・生命を客観的に「聖なる」と信じることも条件ではありません。

畏敬は大切にしますか？

はい。ただし畏敬はTruthの証明ではありません。宇宙、深い時間、生命、意識等について知ることで驚きや畏敬を感じることはありますが、その感情から宇宙目的や超自然的Truthを推論しません。

死後の世界はあると考えますか？

現時点で、死後に個人の意識が存続すると断定できる十分なEvidenceがあるとは考えていません。同時に「絶対に存在しない」と証明されたとも扱いません。分からないことは、分からないままにします。

Founderを信じる必要がありますか？

ありません。Founderには創設者として制度・ブランド・統治上の特別な地位がありますが、Founderの発言だけでFactが正しいことにはなりません。

教えが間違っていたら？

経験的な主張は直します。新しい研究や反証によって理解が変わればWorking Canonを改訂します。

礼拝では何をしますか？

最小礼拝は3〜5分程度です。止まる → 見る → 分ける → 選ぶ → 動く。崇拝・服従すべき外部対象を必須とはしません。

礼拝には科学的根拠がありますか？

構成要素の一部にはあります。一方、この3〜5分の組み合わせ全体が完成した介入として有効だと証明済みではありません。Pilotと改訂を続けます。

医療や心理支援より礼拝を優先しますか？

しません。礼拝は医療・心理療法・公的支援の代替ではありません。専門支援の利用を信仰不足とは扱いません。

献金は必要ですか？

参加や救済、宗教的地位を購入する仕組みにはしません。Community fundingとFounder / Commercial layerは分離する方針です。現段階では正式Membership・会費制度は未確定です。

辞められますか？

はい。参加、礼拝、将来のCircleやCommunityから離れることを宗教的失格や不幸の原因とは扱いません。

何を救いと考えますか？

分からないことを分からないまま認め、苦しさの中でも現実・他者・自分が大切にしたいものへつながり直し、次の一歩を選べる状態へ戻ること。

これをWorking termとして「現実への帰還」と呼んでいます。
