MINIMUM WORSHIP / 3–5 MINUTES

まず3分だけ、
試してみてください。

考えがまとまらないとき。不安や怒りですぐ反応しそうなとき。大事なことを決めたいのに、何から考えればいいか分からないとき。

特別な道具はいりません。何かを信じる必要もありません。

止まる → 見る → 分ける → 選ぶ → 動く

  1. 止まる

    今の動作を一度止めます。できそうなら片手を胸、もう片方を腹へ軽く置きます。手の温かさ・圧・呼吸の動きを感じ、2〜3回、苦しくない呼吸をします。最後の吐息で肩と手の余分な力を少し抜きます。

    胸や腹への接触が嫌なら、前腕・上腕・両手への接触や、省略でも構いません。

  2. 見る

    今起きていることを、事実 / 自分の解釈 / まだ分からないことに分けます。

    「返事が来ていない」＝事実
    「嫌われたかもしれない」＝解釈
    「なぜ返事が来ないのか」＝まだ分からない

  3. 分ける

    自分で動かせる / 誰かとなら動かせる / 今は動かせないへ分けます。全部を自分の責任にする必要も、「何もできない」と決める必要もありません。

  4. 選ぶ

    この状況で、自分は何を大切にしたいだろう。

    健康、家族、休むこと、誠実さ、自由、学ぶこと、距離を取ること、誰かを助けることかもしれません。ここは科学が一つの正解を命令する部分ではありません。

  5. 動く

    次にすることを一つだけ決めます。「もっと頑張る」ではなく、できればいつ・何をするかまで具体化します。

    昼休みになったら、病院へ電話する。
    21時になったら、今日は作業を終える。

うまくできたかを採点しません。

全部できなくても構いません。気持ちがすぐ楽にならなくても失敗ではありません。この実践は、幸福な気分を無理につくるためのものではありません。

現実を少し正確に見て、自分の状態を整理し、自分で選んだ次の一歩へ戻るためのものです。

科学的根拠について

呼吸、身体への注意、感情の言語化、問題整理、Value clarification、implementation intentionなど、構成要素には心理学・行動科学等の研究があります。

重要：この3〜5分の組み合わせ全体が、完成した一つの介入として有効だと証明済みなわけではありません。Pilotで検証し、Evidenceが変われば直します。

苦しいときほど、ここへ戻る。

分からないものを、分かったことにはしない。
動かせないものに、自分のすべてを渡さない。
大切にしたいものを一つ選び、次の行為へ戻る。
一人で戻れないときは、他者と戻る。

強い希死念慮、DV、psychosis、急性の身体症状などは、礼拝だけで解決しようとせず、適切な医療・心理・公的支援を利用してください。
