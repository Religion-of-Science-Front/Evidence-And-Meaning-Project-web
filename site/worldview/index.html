WORLDVIEW / VALUE / AWE

私たちは自然の外にいない。

身体も、生命も、意識も、文化も、関係も、自然的現実の外部にあるものとは考えません。その中で、私たちは有限な時間だけ世界を経験しています。

分からないことを、分かったことにはしない。

死後の意識、宇宙の目的、意識の最終的な本質、人生の絶対的意味。安心のために答えをつくらず、Evidenceが変わればFact理解を更新します。

科学は、価値そのものを決めない。

科学は、世界がどうである可能性が高いか、ある行動がどんな結果を生みやすいかを知る強い方法です。しかし、誰を愛するか、何に時間を使うか、何を守るかを科学だけで決めることはできません。

FactとValueを分けたうえで、知識を自分の生き方へ接続します。

「自然だから聖なる」とは言わない。

自然の連続性というWorldviewから、対象が客観的に聖なるというValueは自動的には導かれません。

Worldview

人間、生命、意識、社会は自然的現実の内部にある。

Awe

宇宙、深い時間、生命、意識等を知ることで畏敬を感じることはある。しかし感情はTruthの証明ではない。

Value

有限な生命と他者の主体性を、単なる手段としてだけ扱わないことを私たちは選ぶ。

意味は、与えられるのを待つだけではない。

宇宙から自分専用の使命が配布されているとは約束しません。それでも、関係、選択、仕事、育てたもの、守った人、残した言葉、失敗から変えたことの中で意味を形成できます。

死について

私が永遠に残るのではない。
私が存在したことによって世界に生じた差分が残る。

これは死後の個人意識を保証する言葉ではありません。記憶、関係、行動、知識、作品、制度、文化など、人が現実へ残す差分を表すSymbolic expressionです。

この世界観を、どう生きるか。

有限だからこそ、今ここにある生命と関係を軽く扱わない。
それは自然から命じられた結論ではなく、私たちが引き受けるValueです。
